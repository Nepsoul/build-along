# Build Along
 
A project-based learning repo where I build real projects by following video tutorials. I use it to turn what I watch into working code, practice new tools, and keep a record of my progress.
 
## How I Learn
 
1. **Watch:** Understand what the project does and how it's approached.
2. **Build:** Code along, pausing to make sure I understand each step.
3. **Extend:** Add a feature, fix a problem, or change something on my own.
4. **Document:** Write down what I learned in the project's README.
## Projects
 
Each project has its own folder with a README covering its details, setup, and what I learned.
